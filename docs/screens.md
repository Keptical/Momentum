# Screens

## Home Dashboard

Purpose:
Show the user's current momentum and today's priorities.

Contains:

- Greeting
- Momentum trend graph
- Today's workout
- Habit progress
- Tasks
- Current streak


## Workout Screen

Purpose:
Allow quick workout tracking.

Contains:

- Current workout
- Exercise list
- Add exercise button
- Set logging


## Habits Screen

Purpose:
Track daily consistency.

Contains:

- Active habits
- Completion buttons
- Streaks
- History


## Planner Screen

Purpose:
Organise daily tasks.

Contains:

- Today's tasks
- Upcoming tasks
- Add task button


## Profile Screen

Purpose:
Manage account and settings.

Contains:

- User information
- Goals
- Settings
- Statistics
