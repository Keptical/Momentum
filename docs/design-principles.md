# Design Principles

## Simplicity

If a feature can be completed in fewer taps, do it.

## Consistency

Buttons and navigation should behave the same throughout the app.

## Fast

Users should be able to log a workout set in under 5 seconds.

## Clarity

Never hide important information.

## Motivation

The app should encourage progress without making users feel guilty for missing a day.

## Spacing
