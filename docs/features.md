# Momentum Features

## Dashboard

Purpose:
The main screen that shows the user's current progress and what needs attention today.

Core Features:
- Momentum trend graph
- Weekly progress comparison
- Today's workout
- Today's habits
- Today's tasks
- Current streak / - Consistency indicator

---

## Workout Tracker

Purpose:
Allow users to quickly record and track workouts.

Core Features:
- Create workouts
- Add exercises
- Track sets
- Track reps
- Track weight
- View workout history

Design Goal:
Logging a set should take as few taps as possible.

---

## Habit Tracker

Purpose:
Help users build consistent daily routines.

Core Features:
- Create habits
- Complete habits
- Track streaks
- View completion history

---

## Planner

Purpose:
Help users organize their day.

Core Features:
- Create tasks
- Set deadlines
- Mark complete
- Set priority

---

## Statistics

Purpose:
Show users their progress over time.

Core Features:
- Workout frequency
- Habit completion rate
- Tasks completed
- Weekly progress

---

# V1 Non-Goals

Features that will NOT be built initially:

- Social features
- AI coach
- Nutrition tracking
- Wearables
- Leaderboards
