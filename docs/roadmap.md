# Momentum Roadmap

## Vision

Momentum is a mobile app designed to help users build consistency across fitness, habits, and productivity.

---

## V1

- Authentication
- Dashboard
- Workout tracker
- Habit tracker
- Planner
- Basic statistics

- Primary Navigation : (bottomNavBar) Things users do everyday, 
- Secondary Navigation : (TopBar, showing username and pfp) Things users want but dont need permanently displayed.
---

## V2

- Notifications
- Calendar improvements
- Themes
- Offline mode

## V3

- AI planning
- Smart scheduling
- AI workout suggestions
